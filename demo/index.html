    How it works

    Type slower than 0.1 s per key
    Faster than that and a turtle-rage window locks the editor for two seconds.
    Stay calmer than 0.5 s per key
    The turtle is proud. Anything in between is “steady typing”.
    Press Run
    Your code runs as Python right in the page (via Pyodide), with please() built in — then the compiler answers with a haiku.
    Lazy Mode
    Forgives fast fingers and stops the compiler’s 1-in-10 lazy refusals.

    Prefer the desktop original? Get slowLang on GitHub — python ui-fakeide.py and type gently.

    🐢 TortoiseLang – Slower is Better

    • Python-like syntax: write code just like Python.
    • Speed enforcement: typing too fast triggers sarcastic errors and turtle rage.
    • Sarcastic feedback: sassy remarks and poetic haikus if you break the rules.
    • Run code like Python with the “Run (like Python)” button.
    • The compiler sometimes pops words of wisdom after execution.

    Close the rage window early and you lose your right to code. (Not really. The turtle just judges you.)
